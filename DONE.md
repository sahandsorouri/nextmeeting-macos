## Latest session — alerts + menu bar format
- **3.2 Pre-meeting notifications.** `Sources/NotificationManager.swift` schedules
  native local notifications 1/5/10 min before each meeting (user-selectable in the
  popover). `AppDelegate` (via `@NSApplicationDelegateAdaptor`) is the
  `UNUserNotificationCenter` delegate: shows banners even when frontmost, and opens
  the join link when a notification is tapped. Rescheduled on every `reload()` so it
  tracks calendar changes. Off by default; asks permission on enable. Added
  `NSUserNotificationsUsageDescription` to Info.plist. 100% on-device.
- **2.4 Menu bar format options.** New settings: "Title in bar" toggle, "Title length"
  (10/15/20/30), and "Time format" (12h/24h, applied to dropdown times via
  `Format.time`). `MenuBarLabel` honors show-title + length.

## Tier 3 — Distribution (in progress)
- **3.6 DMG packaging.** `./package_dmg.sh` builds a universal app, stages it with an
  `/Applications` symlink, and creates a compressed UDZO `.dmg` named by version
  (`build/NextMeeting-<version>.dmg`, ~816K). Verified by mounting: contains the
  universal app (x86_64 + arm64) + drag-to-Applications link. Not notarized → first
  launch on another Mac needs right-click → Open.
- **3.4 Universal build.** `./build.sh universal` compiles arm64 and x86_64 slices
  separately, merges them with `lipo`. `./build.sh` (no arg) still does a fast
  native-arch dev build; `run` launches; args are order-independent.
- **3.1 App + menu bar icons.** App icon: custom calendar+play glyph generated by
  `Scripts/generate_icons.swift` (CoreGraphics/ImageIO, **compiled** — the `swift`
  interpreter stalls on module-cache writes in this iCloud workspace) → `.iconset` →
  `Resources/NextMeeting.icns` (via `iconutil`, falling back to `Scripts/make_icns.mjs`).
  Shown in Finder + the About panel.
  - Menu bar **idle** icon: after several oversized attempts with a custom PNG, switched
    to the native SF Symbol `calendar`. Root cause found via `Scripts/calibrate.swift`,
    which measures ink bounding boxes: the system glyph fills ~94% of its canvas, our
    PNG only ~70%, AND `MenuBarExtra` stretches a resizable custom image to the full bar
    height — so it always looked too big. The SF Symbol renders at the exact system
    standard. (The custom glyph lives on as the app icon.)
- **3.3 About / version.** Native standard About panel via `About.show()` (shows the
  app icon + version from Info.plist). "About" button added next to Refresh/Quit in
  the popover.
